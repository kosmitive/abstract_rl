# Temporal Difference Data

There are at most two types of TD-data:

## Trajectories

They are the project's main data structure. A `TrajectoryCollection` holds E lanes (one episode per lane, padded to
`max_steps`) as stacked JAX arrays. It is generated by `MCMCEnvWrapper.execute_policy`, which runs all lanes in one
jitted loop.

## Batches

A batch is a shuffled version of the trajectories. They can be generated by a `TrajectoryCollection`.
